# Theme 07 — The "Meta" Content: Process & Engineering Systems · Audience: Mixed Beginner → Intermediate

> The habits that make solo projects not fall apart: writing things down,
> recording decisions, and structuring a repo so a future-you can navigate it.

## Catalog

### G4 (intro) — Write it Down: Decision Records for Your Side Project
- **Difficulty:** Beginner
- **Type:** Practice guide
- **Hook:** "Future-you will thank present-you for one good ADR."
- **Description:** A beginner-friendly intro to ADRs using real examples
  (Why did we pick this chat architecture? Why these branches?), with a copyable
  template and lifecycle tips.
- **Grounding:** `docs/decisions/README.md`.
- **Sellable angle:** Low-friction entry point to professional-practice content.

### G1 (intro) — Plan First, Ticket Second, Code Third
- **Difficulty:** Beginner
- **Type:** Workflow guide
- **Hook:** "A one-page plan + tiny tickets beats a brilliant brain-dump."
- **Description:** The doc-driven loop simplified: a plan summary, per-phase
  detail files, tickets with acceptance criteria, and a simple counter to keep
  numbering sane. Reader can adopt it on week one.
- **Grounding:** `docs/diagrams/agents/FLOW.md`.
- **Sellable angle:** Adoptable-this-afternoon workflow content.
