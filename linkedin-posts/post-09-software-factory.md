# My AI Agents Write, Review, Test, and Deploy My Code

I built a software factory where AI agents implement my tickets end-to-end.

No more "write this function" one-off prompts. My setup runs a full pipeline:

1. A team-lead agent plans and splits work into tickets
2. Developer agents implement each ticket in isolated git worktrees
3. A reviewer does QA, a tester runs the suite
4. GitHub CI/CD merges and auto-deploys to Kubernetes

Grounded by a docs + code RAG so agents retrieve context instead of burning tokens re-reading the repo.

Bleeding-edge, and it ships my AI Sport Agent platform.
