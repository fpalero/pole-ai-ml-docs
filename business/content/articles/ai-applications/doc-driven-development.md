# Documentation-Driven Development: PLAN → Tickets → RAG

**Section:** AI Applications

## What it delivers
A project where every feature stays traceable and queryable — documentation
acts as the steering wheel, not a post-hoc report.

## How it's built
Plan-first workflow: PLAN.md, per-phase plans, tickets with acceptance criteria
and effort, then a docs RAG so agents and engineers retrieve decisions on
demand.
