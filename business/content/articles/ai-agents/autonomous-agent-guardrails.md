# Guardrails for Autonomous Coding Agents

**Section:** AI Agents

## What it delivers
The safety layer that lets an agent crew ship code without full human
supervision — autonomy you can trust.

## How it's built
Bounded executions, policy checks, small-step PR gates, and decision records
that say why — rails in place before agents are allowed to implement tickets.

## Proof
- **Code:** [crew](https://github.com/fpalero/pole-ai-ml/tree/develop/crew)
- **Live in the pole app:** every agent PR is gated by CI + review
