# From Local Docker to k3s with Helm

**Section:** AI Applications · **Featured:** ✅

## What it delivers
One recipe that takes an ML stack from a laptop to a production cluster — so
"it runs on my machine" stops being the last mile of your product.

## How it's built
docker-compose for local dev, then k3s with Helm charts, health probes, Traefik
ingress, Trivy scans, and GitHub Actions deploying per environment.
