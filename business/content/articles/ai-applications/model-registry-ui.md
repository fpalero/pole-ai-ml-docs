# Model Registry UI: The Human Gate for ML Deploys

**Section:** AI Applications

## What it delivers
A screen where model runs are reviewed, compared, and promoted by a human —
so "deploy this model" is a deliberate decision, not an accident.

## How it's built
A registry UI with live epoch progress, per-class metrics, a two-run
comparison matrix, and an approve/activate action that flips the active pointer.
