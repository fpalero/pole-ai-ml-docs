# Branding Keycloak: On-Brand Identity Pages

**Section:** AI Applications

## What it delivers
Login and account pages that feel like your product, not a default install —
so the first thing a user sees isn't a generic form.

## How it's built
Keycloak themes as source of truth: FreeMarker page templates, a full visual
restyle from shared design tokens, and realm settings shipped together in the
infra repo.
