# The Crew: LLM Agents Implementing Their Own Tickets

**Section:** AI Agents

## What it delivers
A working agentic-coding pipeline — team-lead plans, developer/reviewer/tester
agents implement, and PRs flow through CI — so shipping becomes an orchestrated
system, not a solo grind.

## How it's built
Team-lead plan → backlog → implementation, orchestrating developer, reviewer,
and tester agents over an LLM provider factory, ticket lifecycle state, and
per-ticket repo routing.
