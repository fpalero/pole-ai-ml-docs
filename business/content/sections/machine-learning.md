# Section 4 — Machine Learning

## Service description (outcome-first)

Computer-vision and deep-learning systems that read your data and make
decisions — from pose estimation and biomechanical features to embeddings,
classification, and vector search. Trained honestly on small data and
deployable in the browser. I build ML that ships, not models that live in a
notebook.
