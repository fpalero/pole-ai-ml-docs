# Automatic Phase Detection in Sports Video

**Section:** Machine Learning

## What it delivers
A trick segmented automatically into entrance, execution, and exit — no manual
frame marking — so analysis is structured and comparable.

## How it's built
Reference data and metric time-series drive phase detection, with documented
failure modes when phases drift.
