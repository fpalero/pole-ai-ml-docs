# AI-Generated UI at Feature Scale

**Section:** AI Applications

## What it delivers
Coherent, AI-produced frontends across many features — when the product *is*
the UI, orchestration keeps it from fragmenting.

## How it's built
Phase-by-phase shell, tab/sidebar navigation, detail modals, upload-progress
panels, and parity checks across generated views.
