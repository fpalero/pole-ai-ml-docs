# Defensive Training: Leave-One-Out + Categorical Crossentropy

**Section:** Machine Learning

## What it delivers
Honest evaluation on tiny labeled datasets — so you don't fool yourself (or a
client) with a single optimistic accuracy number.

## How it's built
Leave-One-Out splits, early stopping, learning-rate scheduling, and per-class
metrics used as a release gate.
